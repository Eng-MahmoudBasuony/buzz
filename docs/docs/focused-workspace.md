# Focused home and transcript studio

The home opens with a YouTube link field, language and model controls, and a single Start transcription action. Review advanced settings opens the existing transcription dialog without starting work. The file tab keeps the existing file chooser and settings review. Recording, preferences, and the full library remain available in the navigation.

Recent transcript cards read the same SQLite records as the library. Queue status comes from the real download/transcription phase; an indeterminate progress bar is shown when a numeric estimate is unavailable. Opening, canceling, and deleting use the existing handlers. Library search filters visible rows without changing the database.

The dark transcript studio has a recent-transcript pane, an editable transcript, and source details. Local video files use the existing video player. YouTube imports that retain only audio offer audio playback and an Open source video button. The source file or URL remains selectable and read-only.

The timeline draws the existing decoder's actual audio samples and supports seeking and keyboard navigation. It stays a plain seek track while samples load. Silent audio produces a flat waveform. Text edits, timestamps, speaker assignment, translation review, and export continue through the existing database and editor paths.

Arabic and Latin paragraphs use their own reading direction, timestamps and source addresses stay left-to-right, and the two workspace palettes are scoped to their windows. Merely opening a saved transcript no longer requests Keychain access; translation credentials are loaded only when needed.

Tests use isolated settings, databases, credentials and audio. No paid transcription is required to validate the redesign.
