من فيديو يوتيوب إلى نص، بضغطة واحدة

الحزمة دي بتثبّت إضافة Buzz وتربطها بالبرنامج، من غير تنزيل السورس كود أو تثبيت أدوات برمجة.

  1. ثبّت نسخة Buzz للماك داخل Applications.
  2. فكّ ضغط حزمة الإضافة، ثم انقر مرتين على Install Buzz Extension.command. انتظر رسالة اكتمال التثبيت، وبعدها اقفل Buzz وافتحه تاني مرة واحدة.
  3. افتح Chrome واكتب chrome://extensions في شريط العنوان، وفعّل Developer mode.
  4. اختر Load unpacked. اضغط Command + Shift + G والصق المسار ده: ~/Library/Application Support/Buzz/Chrome/extension ثم اضغط Open. لو عندك نسخة Buzz قديمة في Chrome محمّلة من مجلد آخر، احذف الإضافة القديمة أولًا.
  5. ثبّت أيقونة Buzz — YouTube to Text بجوار شريط العنوان. افتح فيديو يوتيوب واضغط عليها؛ النص هيفتح تلقائيًا في Buzz لما يخلص.

اختَر النموذج ولغة الفيديو من Buzz. للاستخدام المجاني، نزّل نموذجًا محليًا مرة واحدة. استخدام API اختياري وتكلفته حسب مزوّد الخدمة.

تقدر تحذف مجلد الحزمة من Downloads بعد التثبيت. احتفظ بمجلد الإضافة داخل Library. عند تحديث الحزمة، شغّل ملف التثبيت ثم اضغط Reload على بطاقة الإضافة في Chrome.

Quick start

  1. Install the matching Buzz.app in Applications and extract this setup ZIP.
  2. Double-click Install Buzz Extension.command. It installs a permanent copy and registers the connection to Buzz. Quit and reopen Buzz once afterward. No Python, uv, repository checkout or administrator password is required.
  3. Open chrome://extensions, enable Developer mode, and select Load unpacked. Use Command+Shift+G to select:~/Library/Application Support/Buzz/Chrome/extension
  4. Remove an older Buzz extension loaded from a different folder first. Pin the Buzz toolbar icon and click it on a YouTube video.

Local models must already be downloaded in Buzz. Optional API usage is billed separately by the provider. This package does not contain or request API keys.

On an update, rerun setup and reload the extension in Chrome. You may delete the downloaded setup folder afterward; keep the installed extension folder.
