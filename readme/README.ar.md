# Buzz — نسخة محمود بسيوني

[English](../README.md) · [المشروع الأصلي](https://github.com/chidiwilliams/buzz) · [توثيق المشروع الأصلي](https://chidiwilliams.github.io/buzz/)

حوّل الصوت وملفات الفيديو وفيديوهات يوتيوب إلى نص، ثم راجعه وعدّله وصدّره.
تعمل النماذج المحلية على جهازك، ويمكن استخدام خدمات API اختياريًا بتكلفة
يحسبها مزوّد الخدمة بشكل منفصل.

هذه نسخة مستقلة مشتقة «فورك» من **[Buzz](https://github.com/chidiwilliams/buzz)**،
الذي أنشأه **Chidi Williams** وساهم في تطويره مجتمع المشروع. يتولى
**[محمود بسيوني](https://github.com/Eng-MahmoudBasuony)** صيانة الإضافات في هذا
الفورك. هذه النسخة ليست إصدارًا رسميًا من المشروع الأصلي، ويظل
[ترخيص MIT وإشعار حقوق النشر الأصلي](../LICENSE) محفوظين.

## إضافات هذه النسخة

- **رئيسية تركز على المهمة:** إدخال رابط يوتيوب، واختيار اللغة والنموذج،
  ومتابعة حالة التفريغ الفعلية، والوصول إلى آخر النصوص ومكتبة قابلة للبحث.
- **محرر نصوص داكن:** تعديل المقاطع وتوقيتاتها، وعرض تفاصيل المصدر، والبحث،
  والتحكم في التشغيل، والتنقل عبر مخطط مرسوم من الصوت الفعلي.
- **واجهة عربية بصياغة احترافية:** ترجمة حسب سياق الاستخدام، واتجاه من
  اليمين إلى اليسار، وترجمة الإضافات المرفقة. تحتفظ الروابط والمسارات
  والتوقيتات والأكواد اللاتينية باتجاهها الطبيعي. لغة الواجهة مستقلة عن
  لغة الصوت المراد تفريغه.
- **تفريغ يوتيوب بضغطة من Chrome:** إرسال الفيديو المفتوح إلى Buzz، وبدء
  التفريغ، وفتح النص تلقائيًا عند اكتماله. الضغط على الفيديو نفسه مرة أخرى
  يفتح النتيجة المحفوظة بدلًا من إعادة التفريغ.
- **تحسين موثوقية التفريغ:** استئناف التفريغ عبر خدمات API للملفات وفيديوهات
  يوتيوب، وإظهار مراحل العمل بوضوح، وإعادة المحاولة بطلب صريح. يبقى مفتاح
  API داخل Buzz. لا يتطلب تجهيز مهام الملفات ويوتيوب بنموذج محلي، أو فتح
  النصوص المحفوظة، الوصول إلى Keychain.

تحتفظ النسخة بميزات Buzz الأصلية، ومنها نماذج التفريغ المحلية، والتسجيل
من الميكروفون، وفصل الكلام وتمييز المتحدثين، ومراقبة المجلدات، والإضافات،
والتصدير بصيغ **TXT وSRT وVTT**. راجع
[التوثيق الأصلي](https://chidiwilliams.github.io/buzz/) لباقي الميزات.

## الحصول على هذه النسخة

جُرّبت النسخة المعدلة والتكامل مع Chrome على **macOS بمعالجات Apple Silicon**.
يدعم موصل المتصفح حاليًا **macOS وGoogle Chrome**؛ ولم يُتحقق من هذا التكامل
بالمستوى نفسه على الأنظمة الأخرى.

**لم تُنشر حزمة تثبيت ضمن إصدارات هذا الفورك حتى الآن.** ستكون الحزم الخاصة
به متاحة عند نشرها في [صفحة الإصدارات](https://github.com/Eng-MahmoudBasuony/buzz/releases).
تخص حزم SourceForge ومتاجر التطبيقات وحزمة `buzz-captions` على PyPI المشروع
الأصلي، ولا تتضمن التعديلات الخاصة بهذا الفورك.

للتطوير، استخدم هذا المستودع مع مستودعاته الفرعية، واختر الفرع أو وسم الإصدار
الذي يحتوي على التعديلات المطلوبة. يمكن متابعة تعديلات الواجهة والمتصفح في
[طلب الدمج رقم ٣](https://github.com/Eng-MahmoudBasuony/buzz/pull/3).
تتطلب الشيفرة الحالية **Python 3.13** وفق
[pyproject.toml](../pyproject.toml). راجع [دليل المساهمة](../CONTRIBUTING.md)
لمتطلبات النظام والتطوير، مع استخدام رابط هذا الفورك عند الاستنساخ.
توجد إعدادات بناء الحزم في [Makefile](../Makefile) و[Buzz.spec](../Buzz.spec).

## تفعيل الواجهة العربية

اختر **الإعدادات ← عام ← لغة الواجهة ← العربية**، ثم أعد تشغيل Buzz.
حدّد لغة الصوت بشكل منفصل عند بدء التفريغ.

التفاصيل في [دليل الواجهة العربية](../docs/docs/arabic-ui.md)
و[دليل الرئيسية والمحرر](../docs/docs/focused-workspace.md).

## إعداد إضافة Chrome

1. ثبّت نسخة متوافقة من هذا الفورك في `/Applications/Buzz.app`.
2. من نسخة مجهزة من الشيفرة المصدرية، سجّل الموصل المحلي:

   ```sh
   uv run --no-sync python scripts/install_browser_extension.py
   ```

3. افتح صفحة إدارة إضافات Chrome، وفعّل **Developer mode**، ثم اختر
   **Load unpacked** وحدّد مجلد `browser-extension` داخل المستودع.
4. ثبّت أيقونة **Buzz — YouTube to Text** في شريط المتصفح. افتح صفحة فيديو
   يوتيوب واضغط الأيقونة؛ سيفتح Buzz النص تلقائيًا بعد اكتمال التفريغ.

تستخدم الإضافة النموذج واللغة المحفوظين في Buzz. نزّل نموذجًا محليًا أولًا،
أو اضبط خدمة API داخل البرنامج. تُحسب تكلفة API، إن وُجدت، لدى مزوّد الخدمة الذي تختاره.
لا يصل مفتاح API إلى الإضافة، وصلاحياتها تقتصر على `activeTab` و`nativeMessaging`.

يجب فتح صفحة فيديو؛ صفحات القنوات وقوائم التشغيل غير مقبولة. إغلاق النافذة
المنبثقة لا يلغي المهمة التي أُرسلت بالفعل. تحتاج المهام الفاشلة أو الملغاة
إلى إعادة محاولة صريحة. راجع [دليل الإضافة](../browser-extension/README.md)
للتفاصيل وطريقة إزالتها.

## التحقق من عمل النسخة

شمل الاختبار الفعلي للبرنامج المثبت على الماك:

- تفريغ عيّنة عربية محليًا، وفتح النص وتعديله، ثم إعادة فتحه للتحقق من حفظ التعديل.
- تصدير TXT وSRT وVTT، وفحص النص والتوقيتات في الملفات الناتجة.
- الضغط على الإضافة من صفحة فيديو يوتيوب لم يُفرّغ من قبل: فتح Buzz، وتفريغ
  الفيديو محليًا، وظهور النص تلقائيًا دون ضغطة أخرى.
- فتح النتيجة المحفوظة من الإضافة دون إنشاء عملية تفريغ ثانية للفيديو نفسه.

نجحت أيضًا اختبارات موجهة لـPython وQt وJavaScript الخاصة بالإضافة.
تتحقق هذه الاختبارات من سير العمل؛ وتختلف دقة التعرف على الكلام حسب الصوت والنموذج.
